# UI Screens

Every page of the app by route, with a screenshot where one exists (desktop 1440x900, mobile 390x844; regenerated by `scripts/capture_all_screens.py`, which needs both dev servers). The same routes with their guards are in [route_map.md](route_map.md).

Student pages are open to admins too. A parent who opens one is redirected to `/parent/dashboard`, except `/profile`, `/settings` and `/join-class`.
